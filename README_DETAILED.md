## 📋 Описание проекта

**Text-Ai** - это полнофункциональное веб-приложение для распознавания и извлечения текста из изображений. Приложение обеспечивает удобный интерфейс для загрузки изображений и автоматического распознавания содержащегося в них текста на русском и английском языках.

Проект демонстрирует интеграцию современных технологий машинного обучения с веб-приложениями, включая:
- **Backend** на Flask для управления запросами и обработки данных
- Использование **нейронных сетей** для обработки и классификации символов
- Поддержку **ускорения на GPU** через CUDA
- Простой и интуитивный **веб-интерфейс**

**Основная цель:** Предоставить инструмент для быстрого и точного распознавания текста из изображений через веб-приложение без необходимости установки дополнительного ПО.

## 🔧 Основные компоненты

### 1. Flask - Веб-сервер (main.py)

**Расположение:** `main.py` (в корне проекта)

**Назначение:** Flask является основным веб-фреймворком приложения и отвечает за все операции, связанные с веб-приложением.

**Основные функции:**
- 📡 Запуск HTTP сервера на порту 8080
- 🌐 Рендеринг HTML страниц
- 📥 Обработка загруженных файлов от пользователя
- 🛣️ Маршрутизация запросов (routing)
- ⚙️ Управление конфигурацией приложения
- 📝 Логирование и обработка ошибок

**Основные маршруты (routes):**

#### Маршрут: `/` (GET)
```
Назначение: Отображение главной страницы
Метод: GET
Ответ: HTML страница с формой загрузки изображения
```

#### Маршрут: `/action` (POST)
```
Назначение: Обработка загруженного изображения и распознавание текста
Метод: POST
Параметры: файл изображения (form-data)
Ответ: HTML страница с результатом распознавания
```

**Конфигурация:**
```python
MAX_CONTENT_LENGTH = 8 * 1024 * 1024  # Максимальный размер файла: 8 МБ
Хост: 127.0.0.1 (localhost)
Порт: 8080
```

**Процесс обработки запроса:**
1. Пользователь выбирает изображение на веб-странице
2. Форма отправляет POST запрос на `/action`
3. Flask получает файл и проверяет его формат
4. Файл сохраняется в папку `base/`
5. Файл передается в EasyOCR для обработки
6. EasyOCR возвращает распознанный текст
7. Flask отправляет результат обратно пользователю

### 2. TensorFlow и Keras - Фреймворки для нейронных сетей

**Расположение:** `ai/ai.py` (папка ai)

**Назначение:** TensorFlow и Keras используются для создания, обучения и использования нейронных сетей для распознавания символов.

**Важно:** В текущей версии приложения эта функциональность **не используется активно**, однако она составляет основу для потенциального развития проекта и демонстрирует архитектуру нейронной сети.

#### Класс Ocr
Основной класс для работы с распознаванием текста на базе нейронных сетей.

**Параметры инициализации:**
```python
class Ocr:
    IMAGE_SIZE = 48              # Размер входного изображения (48x48 пиксели)
    CHARSET = (                  # Набор поддерживаемых символов
        "0123456789" +           # Цифры
        "abcdefghijklmnopqrstuvwxyz" +  # Английские строчные буквы
        "ABCDEFGHIJKLMNOPQRSTUVWXYZ" +  # Английские прописные буквы
        "абвгдеёжзийклмнопрстуфхцчшщъыьэюя" +  # Русские строчные буквы
        "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"    # Русские прописные буквы
    )
```

#### Ключевые методы:

**`__init__(model_path: str | None = None)`**
- Инициализирует OCR агент
- Загружает или создает модель нейронной сети
- Параметр `model_path`: путь к сохраненной модели (опционально)

**`_render_char(char: str) -> np.ndarray`**
- Отрисовывает символ на изображение (48x48)
- Применяет случайные трансформации:
  - Случайный поворот (-10 до +10 градусов)
  - Изменение контраста (0.8-1.3x)
  - Размытие по Гауссу
  - Добавление шума
- Используется для генерации синтетических тренировочных данных

**`_build_synthetic_dataset(samples_per_char: int) -> tuple[np.ndarray, np.ndarray]`**
- Генерирует синтетический набор данных для обучения
- Создает `samples_per_char` примеров для каждого символа
- Возвращает массив изображений и соответствующие метки

**`create_model(epochs: int = 8, batch_size: int = 64, samples_per_char: int = 120) -> bool`**
- Создает и обучает нейронную сеть
- Параметры:
  - `epochs`: количество эпох обучения (по умолчанию 8)
  - `batch_size`: размер пакета (по умолчанию 64)
  - `samples_per_char`: количество примеров для каждого символа (по умолчанию 120)
- Возвращает `True` если обучение успешно, иначе `False`

**`_prepare_image(image_path: str | Path) -> np.ndarray`**
- Предварительно обрабатывает входное изображение:
  - Преобразует в черно-белое
  - Автоматически усиливает контраст
  - Применяет медианный фильтр
  - Нормализует значения (0.0-1.0)

**`recognize_text(image_path: str | Path) -> str`**
- Главный метод распознавания текста
- Разделяет изображение на строки
- Для каждой строки распознает символы
- Возвращает распознанный текст

#### Архитектура нейронной сети (CNN)

Модель представляет собой сверточную нейронную сеть со следующей архитектурой:

```
Input (48x48x1)
    ↓
Conv2D(32 фильтра, 3x3) + ReLU
    ↓
BatchNormalization
    ↓
MaxPooling2D(2x2)
    ↓
Conv2D(64 фильтра, 3x3) + ReLU
    ↓
BatchNormalization
    ↓
MaxPooling2D(2x2)
    ↓
Conv2D(128 фильтров, 3x3) + ReLU
    ↓
BatchNormalization
    ↓
MaxPooling2D(2x2)
    ↓
Dropout(0.3)
    ↓
Flatten()
    ↓
Dense(256) + ReLU
    ↓
Dropout(0.3)
    ↓
Dense(118) + Softmax
    ↓
Output (вероятности для каждого символа)
```

**Компоненты:**
- **Conv2D:** Сверточные слои для выделения признаков
- **BatchNormalization:** Нормализация активаций для стабильного обучения
- **MaxPooling2D:** Снижение размерности, сохранение важных признаков
- **Dropout:** Предотвращение переобучения (случайное отключение 30% нейронов)
- **Dense:** Полносвязные слои для классификации
- **ReLU:** Функция активации (Rectified Linear Unit)
- **Softmax:** Преобразование выходов в вероятности для 118 классов

**Параметры обучения:**
```python
Оптимизатор: Adam
Функция потерь: Categorical Crossentropy
Метрика: Accuracy (точность)
Количество классов: 118 (все поддерживаемые символы)
```

## 🐛 Устранение проблем

### Проблема 1: "ModuleNotFoundError: No module named 'easyocr'"

**Причина:** Библиотека EasyOCR не установлена

**Решение:**
```bash
pip install easyocr
```

### Проблема 2: "CUDA not available" но GPU установлена

**Причина:** PyTorch установлен без поддержки CUDA

**Решение:**
```bash
# Удалите текущую версию PyTorch
pip uninstall torch torchvision torchaudio

# Переустановите с CUDA поддержкой
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

### Проблема 3: "Port 8080 already in use"

**Причина:** Порт 8080 уже занят другим процессом

**Решение:**
```python
# Отредактируйте main.py в конце файла:
if __name__ == "__main__":
    app.run(port=8081, host="127.0.0.1")  # Измените порт на 8081
```
