## 📋 Описание проекта

**Text-Ai** - это полнофункциональное веб-приложение для распознавания и извлечения текста из изображений. Приложение обеспечивает удобный интерфейс для загрузки изображений и автоматического распознавания содержащегося в них текста на русском и английском языках.

Проект демонстрирует интеграцию современных технологий машинного обучения с веб-приложениями:
- **Backend** на Flask для управления запросами и обработки данных
- Использование **нейронных сетей** для обработки и классификации символов
- Поддержку **ускорения на GPU** через CUDA
- Простой и интуитивный **веб-интерфейс**

## 🔧 Основные компоненты

### 1. Flask - Веб-сервер (main.py)

**Расположение:** `main.py` (корень проекта)

Flask — основной веб-фреймворк приложения. Он отвечает за:
- 📡 Запуск HTTP сервера на порту 8080
- 🌐 Рендеринг HTML страниц
- 📥 Обработка загруженных файлов
- 🛣️ Маршрутизацию запросов
- ⚙️ Управление конфигурацией

**Маршруты:**
- `GET /` — главная страница с формой загрузки
- `POST /action` — обработка и распознавание изображения

**Процесс обработки:**
1. Пользователь загружает изображение
2. Flask проверяет формат файла
3. Файл сохраняется в `base/`
4. Передается в EasyOCR для обработки
5. Результат возвращается пользователю

---

### 2. TensorFlow и Keras - Нейронные сети

**Расположение:** `ai/ai.py` (папка ai)

TensorFlow и Keras используются для создания и обучения нейронных сетей. Хотя эта функциональность не используется активно, она составляет основу для развития проекта.

**Класс Ocr включает:**
- Метод `__init__()` — инициализация агента
- Метод `_render_char()` — отрисовка символов для тренировки
- Метод `create_model()` — создание и обучение нейросети
- Метод `recognize_text()` — распознавание текста
- Методы для обработки изображений

**Архитектура CNN:**
```
Input (48x48x1)
    ↓
Conv2D(32) → BatchNorm → MaxPool
    ↓
Conv2D(64) → BatchNorm → MaxPool
    ↓
Conv2D(128) → BatchNorm → MaxPool
    ↓
Dropout(0.3) → Flatten
    ↓
Dense(256) → Dropout(0.3)
    ↓
Dense(118) → Softmax
    ↓
Output (символы)
```

**Параметры обучения:**
- Оптимизатор: Adam
- Функция потерь: Categorical Crossentropy
- Метрика: Accuracy
- Классов: 118 символов

**Синтетические данные:**
- Генерируются случайные образцы символов
- Применяются трансформации: поворот, размытие, шум
- Используются для тренировки модели

---

### 3. EasyOCR - Распознавание текста

**Расположение:** `ai/EasyOCR.py`

EasyOCR — основная библиотека для распознавания текста. Класс Ocr включает:

**Метод `__init__()`:**
```python
self.reader = easyocr.Reader(['ru', 'en'], gpu=True)
```
- Инициализирует модель на русском и английском языках
- `gpu=True` включает ускорение на GPU (CUDA)
- Выводит информацию о PyTorch и CUDA

**Метод `result(img)`:**
```python
result = self.reader.readtext(f'base/{img}', detail=0)
return result
```
- Читает изображение из папки `base/`
- `detail=0` возвращает только текст (без координат)
- Возвращает список распознанных строк


## 🐛 Устранение проблем

### Проблема 1: ModuleNotFoundError: No module named 'easyocr'
**Решение:**
```bash
pip install easyocr
```

### Проблема 2: CUDA not available (но GPU установлена)
**Решение:**
```bash
pip uninstall torch torchvision torchaudio
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

### Проблема 3: Port 8080 already in use
**Решение:** Отредактируйте `main.py`:
```python
if __name__ == "__main__":
    app.run(port=8081, host="127.0.0.1")  # Измените на 8081
```

### Проблема 4: Model not found при запуске
**Решение:**
```bash
python
>>> from ai.ai import Ocr
>>> ocr = Ocr()
>>> ocr.create_model()
>>> exit()
```

### Проблема 5: Out of Memory при большом изображении
**Решение:**
- Используйте CPU вместо GPU (в EasyOCR.py измените `gpu=False`)
- Закройте другие приложения
- Уменьшите размер изображения

### Проблема 6: Неправильное распознавание
**Решение:**
- Загружайте четкие изображения
- Избегайте размытости и наклонов
- Используйте разрешение минимум 200x100
