# Text-Ai: Распознаватель текста

## Описание проекта

Text-Ai - это веб-приложение для распознавания текста на изображениях. Приложение использует нейронные сети для извлечения и обработки текста из загруженных изображений. Поддерживает распознавание цифр, английских и русских букв.

## Основные компоненты

### Flask - Веб-сервер
**Файл:** `main.py` (в корне проекта)

Flask является основным веб-фреймворком приложения. Он отвечает за:
- Рендеринг веб-страниц
- Обработку POST запросов от пользователя
- Управление загруженными изображениями
- Маршрутизацию запросов

Сервер работает на адресе `http://127.0.0.1:8080` и имеет два основных маршрута:
- `/` - главная страница с формой загрузки
- `/action` - обработка загруженного изображения

### TensorFlow и Keras - Фреймворки для нейронных сетей
**Файл:** `ai/ai.py` (папка ai)

TensorFlow и Keras используются для создания и обучения нейронных сетей. Хотя эта функциональность не используется в текущей версии приложения, они составляют основу для построения моделей распознавания текста. Код содержит:
- Класс `Ocr` - основной класс для работы с распознаванием
- Методы обучения нейронной сети на синтетических данных
- Архитектуру CNN (сверточной нейронной сети) для классификации символов

## Требования

- Python 3.8 или выше
- PyTorch с поддержкой CUDA (рекомендуется для ускорения)
- Доступ к интернету

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.

2. Установите все зависимости из файла `requirements.txt`:
   ```
   pip install -r requirements.txt
   ```

3. В PyCharm добавьте интерпретатор Python (если не добавлен).

4. Обновите pip:
   ```
   python3 -m pip install --upgrade pip
   ```

5. Установите PyTorch с поддержкой CUDA (замените `cu128` на актуальную версию CUDA, если необходимо):
   ```
   pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu128
   ```

## Запуск приложения

1. Запустите основной скрипт:
   ```
   python main.py
   ```

2. Откройте браузер и перейдите по адресу: `http://127.0.0.1:8080`

3. Загрузите изображение с текстом (поддерживаемые форматы: PNG, JPG, JPEG, BMP, WEBP).

4. Нажмите кнопку "Распознать текст" и получите результат.

**Примечание:** Изображения сохраняются в папку `base/`. Вы можете заменять или добавлять файлы в эту папку для тестирования.

## Ключевые библиотеки

### Flask
Веб-фреймворк для создания HTTP сервера и обработки запросов.

### TensorFlow
Фреймворк машинного обучения для создания и обучения нейронных сетей.

### Keras
API высокого уровня (часть TensorFlow) для удобного построения архитектур нейронных сетей.

### PyTorch
Библиотека для глубокого обучения с поддержкой GPU/CUDA.

### Pillow
Библиотека для обработки изображений (чтение, изменение размера, фильтры и т.д.).

### NumPy
Библиотека для работы с многомерными массивами и математическими операциями.

## Тестирование

В папке `tests/` находятся тесты приложения. Тесты используют матрицы размером 28x28 пикселей для проверки функциональности.

Для запуска тестов:
```
python tests/tests.py
```
