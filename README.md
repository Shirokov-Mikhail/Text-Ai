# Text-Ai: Распознаватель текста

## Описание проекта

Text-Ai - это веб-приложение для распознавания текста на изображениях. Приложение использует технологии OCR (Optical Character Recognition) для извлечения текста из загруженных изображений. Поддерживает распознавание цифр, английских и русских букв.

Приложение построено на базе Flask и использует библиотеку EasyOCR для распознавания текста, а также собственную модель на базе TensorFlow/Keras для дополнительной обработки.

## Требования

- Python 3.8 или выше
- PyTorch с поддержкой CUDA (рекомендуется для ускорения)
- Доступ к интернету для загрузки моделей EasyOCR

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.

2. Установите все зависимости из файла `requirements.txt`:
   ```
   pip install -r requirements.txt
   ```

3. В PyCharm добавьте интерпретатор Python (если не добавлен).

4. Обновите pip:
   ```
   python3 -m pip install --upgrade pip
   ```

5. Установите PyTorch с поддержкой CUDA (замените `cu128` на актуальную версию CUDA, если необходимо):
   ```
   pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu128
   ```

## Запуск

1. Запустите основной скрипт:
   ```
   python main.py
   ```

2. Откройте браузер и перейдите по адресу: `http://127.0.0.1:8080`

## Использование

1. На главной странице нажмите "Добавить картинку" и выберите изображение с текстом (поддерживаемые форматы: PNG, JPG, JPEG, BMP, WEBP).

2. Нажмите кнопку "Распознать текст".

3. Результат распознавания отобразится на странице.

Примечание: Изображения сохраняются в папку `base/`. Вы можете заменять файлы в этой папке для тестирования.

## Зависимости

Основные библиотеки:
- Flask: Веб-фреймворк
- EasyOCR: Библиотека для OCR
- TensorFlow/Keras: Для собственной модели
- Pillow: Обработка изображений
- NumPy: Работа с массивами

Полный список см. в `requirements.txt`.

## Обучение модели

Если модель `text_ocr_model.keras` отсутствует, она будет автоматически обучена при первом запуске. Для ручного обучения запустите:

```python
from ai.ai import Ocr
ocr = Ocr()
ocr.create_model()
```
